# Experimental protocol

See the top-level README for execution, configuration, split and reporting details. The primary runner is `scripts/run_experiments.py` and `run_all.sh`. The original single-run scripts remain for compatibility, but their image robustness modes now use all A001–A060 conditions (or no attacks for explicit diagnostic-only ablation). Use the checkpointed runner for publication experiments.

The complete numerical problem and restricted-orbit certificate are unchanged. `docs/MATHEMATICS.md` documents the original theoretical scope. Experimental math reports the actual integer feature magnitude and the carrier-normalized solver margin separately. A05 certifies maximum margin inside each fixed carrier and cap, not global adaptive-mode optimality. `frontier_exact_reference.py` is a separate reference problem, not the actual embedding algorithm.

Every image robustness case reserves exactly 60 condition rows, even on infeasibility or attack failure. Random seeds are stable across competing methods. Summary results distinguish returned attacks from qualified attacks and pair common host/key/condition results. The baseline calibration ranking is: maximize clean and PSNR qualification, minimize achieved PSNR distance to target, minimize training BER, deterministic strength tie-break. No parameters are tuned on final test images. Baseline original and matched-strength configurations are both retained; the latter are not additional methods. No empirical performance is guaranteed. No external attack framework is included.

The video codec and paced-stream experiments are separate from image attacks. `video_frames60` uses the same exact original attack registry on sampled decoded frames. Video stream rows record user-space queue drops and nominal deadline misses; actual hardware camera drops are unknown. Actual codec results use real FFmpeg encode and decode, not a JPEG proxy. Lossless pixel match, pre-codec quality and post-codec BER are separately reported. Run short smoke checks before long experiments.
